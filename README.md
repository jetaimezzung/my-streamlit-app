# 🐄 COW — Context Over Words

> **“언어는 표현이 아니라 맥락이다.”**  
> 실전에 바로 투입될 수 있는 효율적인 생존 영어.

---

## 🔎 Why COW?

한국인은 문법과 독해 능력이 뛰어나다.  
하지만 실전 회화에서 유연하게 대응하는 사람은 많지 않다.

- 무엇을 먼저 말해야 할지 모르겠고  
- 관계와 분위기를 판단하기 어렵고  
- 예상치 못한 질문에 대응이 막힌다  

문제는 표현 부족이 아니라,  
**맥락을 다뤄본 경험의 부족**이다.

기존 회화 앱은 문장을 가르친다.  
COW는 **상황을 훈련한다.**

---

## 🧠 Core Concept

COW는 단순 영어 학습 앱이 아니다.

> AI 기반 실전 맥락 대응 시뮬레이터

- 문장 암기 ❌  
- 패턴 반복 ❌  
- 상황 분석 → 전략 제시 → 실전 대응 훈련 ✅  

---

## ⚙️ How It Works

### 1️⃣ 자유 맥락 입력

사용자가 실제 상황을 한국어로 입력한다.

예:
- “외국인 교수님께 연구 제안 설명해야 함”
- “회사 미팅에서 상사 의견에 반대해야 함”
- “공항에서 짐 분실 신고해야 함”

---

### 2️⃣ 맥락 구조화 (Context Structuring Engine)

AI가 다음을 분석한다:

- 관계 구조 (상사/동료/친구/고객)
- 목적 (설득/요청/거절/소개)
- 형식 수준 (격식/비격식)
- 문화적 리스크

→ 상황에 맞는 접근 전략 제시

---

### 3️⃣ 생존 발화 생성 (Survival Script)

- 최소 안전 문장  
- 확장 버전  
- 전략적 고급 버전  

단순 번역이 아닌,  
**상황에 맞는 말문 열기 구조 제공**

---

### 4️⃣ 실전 시뮬레이션

AI가 상대 역할을 수행한다.

- 질문 방향 전환
- 예상치 못한 반응
- 압박 상황 생성

→ 실전 대응 유연성 훈련

---

### 5️⃣ 피드백 + 회화 습관 누적 기록

단순 발음 점수는 제공하지 않는다.

대신:

- 맥락 적합성
- 정중성
- 설득 구조
- 대응 유연성

그리고 사용자 회화 패턴을 누적 기록한다:

- 자주 사용하는 표현 유형
- 직설적/소극적 경향
- 반복되는 문장 구조
- 대응 전략의 일관성

→ 반복 훈련 시 개인 맞춤 개선 방향 제시

---

## 🎯 Target Users

- 토익 점수는 높지만 말이 막히는 사람
- 교환학생 / 해외 인턴 준비생
- 글로벌 직무 준비생
- 영어를 “공부”가 아니라 “사용”해야 하는 사람

---

## 🚀 Key Differentiation

| 기존 회화 앱 | COW |
|-------------|------|
| 레슨 기반 | 상황 기반 |
| 문장 중심 | 전략 중심 |
| 발음 점수 | 맥락 적합성 중심 피드백 |
| 패턴 반복 | 실전 대응 훈련 |

## 💡 Philosophy

> 언어는 표현이 아니라 맥락이다.

COW는  
영어를 더 많이 말하게 하는 앱이 아니라,  
**더 적절하게 말하게 만드는 앱**이다.
